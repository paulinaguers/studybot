StudyBot es un bot desarrollado en Python que se conecta con las API de Telegram y Gemini AI y funciona como un asistente de estudio. 
Es parte de la materia Taller de Internet II, y el propósito de este trabajo es aprender a interactuar con diferentes APIs y hacer un deploy en Vercel.
El bot se usa desde Telegram, y algunas de sus funcionalidades incluyen guardar materias, tareas, exámenes, horarios y generar quizzes rápidos de práctica (mediante Gemini) en base al material de estudio cargado por el usuario.
